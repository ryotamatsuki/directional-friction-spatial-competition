## Generative AI / LLM policy

Current LSRS guidance states that LLMs do not qualify for authorship; generative LLM use should be documented in a Methods section or a suitable alternative part when no Methods section exists. AI-assisted copy editing alone does not need declaration.

This project used generative AI beyond copy editing. Therefore:

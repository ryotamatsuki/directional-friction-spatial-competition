# LSRS Generative-AI / LLM Disclosure Note

Checked: 2026-09-03
Official source: https://link.springer.com/journal/12076/submission-guidelines

The live LSRS guidelines state that:

1. an LLM does not satisfy authorship criteria;
2. LLM use should be properly documented in the Methods section, or a suitable alternative part if the manuscript has no Methods section;
3. AI-assisted copy editing alone does not need to be declared;
4. human authors remain accountable for the final manuscript.

This project used generative AI for research assistance and manuscript drafting, not merely copy editing. A disclosure is therefore required before submission.

## Draft factual disclosure for author review

> During preparation of this manuscript, the author used OpenAI ChatGPT for research assistance, symbolic-verification workflow support, and drafting/editing. The author reviewed the resulting mathematical claims, source attributions, and manuscript text and accepts responsibility for the final version.

This is a project draft, not publisher-mandated verbatim wording. Before submission the human author must confirm that it accurately describes actual use and that the stated review/accountability has been completed.

Do not include ChatGPT or any other LLM as an author.
